# Document structure and navigation

Start with the two landmarks in `index.html`. The header identifies the local simulation. The aside contains scope and module selection. The main landmark is a focus target for the skip link and holds the current page. The phone navigation calls the same application handlers.

1. Load the preview with a new browser profile.
2. Press Tab then Enter. Keyboard focus should land on the main workspace.
3. Reduce the viewport to phone width and select Modules. Check that the module list opens and receives keyboard focus.

When adding controls, give every input a visible label and use a real button for operations. Add a module in the fixture registry so desktop and phone expose the same name.

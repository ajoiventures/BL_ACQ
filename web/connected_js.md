# Browser requests and retry behavior

Follow `request`, `setSnapshot` and `submit`. The browser sends same-origin JSON. The server chooses identity and permissions from an HTTP-only session cookie. Received source references and notes are rendered with DOM text content.

A decision carries its evidence version, expected history length and a newly generated operation ID. Drafts instead use the actor's own draft version. After a transport failure, Retry last request resends the identical body and key. A stale write displays the server's conflict so the user can reload. Sign out clears visible workspace state.

The [authenticated service guide](../pilot/founder_service.md) covers the transaction behind these controls.

# Responsive layout

Read the default layout rules in `style.css` before the media queries. The desktop grid places navigation alongside the main workspace. A second grid pairs the queue with the selected record. The phone breakpoint turns those panels into two views backed by the same selection.

1. At 1440 pixels, compare the review queue and evidence inspector side by side.
2. At 390 pixels, select a task, open evidence, then return to Command.
3. At 320 pixels, check for horizontal overflow. Press Tab to inspect the focus indicator and touch a 44-pixel control.

The parcel schematic uses CSS patterns and a real button. Its caption supplies the fixture version. Geographic correctness requires a real data adapter.

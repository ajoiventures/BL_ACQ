# Valuation & Risk page

Open `/valuation.html` through the local Black River founder service. This page has one reading order: identify the asset, edit operating assumptions and event scenarios, set the entry policy, review sources, then calculate. Public equity and operating businesses use the corporate DCF; property uses the property DCF. Each input uses actual USD; percentages are labeled in the form.

The report separates baseline equity value, probability-weighted event-adjusted value, and the margin-of-safety entry ceiling. Reference price, upside, discount to value, and downside probability are distinct outputs. Undated prices are labeled as historical unverified input comparisons. The baseline policy reference and any historical author threshold are displayed separately from the event-adjusted entry ceiling. The three acquisition qualifications stay independent. Below them, the forecast has both a chart and a table in actual USD, followed by scenarios, sensitivity, reverse DCF, source holds, and a saved research record. Chart labels use K/M/B/T abbreviations; the table rounds to whole dollars, while JSON export preserves calculation precision.

When supplied, capital sizing displays proposed units, indicative cost, and cash committed without submitting an order. Obligation reconciliation shows declared, itemized, and unreconciled debt and senior claims. Advanced packet editing exposes these optional inputs without adding a separate approval flow.

The page does not approve or execute transactions. Sign-in permits calculation and evidence recording under the server's authorization rules. Editing any input marks prior results stale and disables saving or exporting them until a new calculation completes. Sources and annual paths can be inspected in the complete advanced request.

Use Tab to reach all controls and assumption help. The sign-in panel has explicit labels; calculation errors are alerts and status updates use a live region. Charts have equivalent tables or labeled values. At narrow widths the input form precedes the report in the same document order.

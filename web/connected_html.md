# Connected review page

Open `/connected.html` on the local founder service. The sign-in form uses the temporary role key from the terminal. After sign-in, the page shows one commercial synthetic parcel, a schematic location, an evidence disclosure, the acting account's note and the shared decision history.

Use Tab to reach the evidence disclosure and Enter to expand it. Save a note with the independent reviewer account. Open the same account in a second profile and reload the checkpoint. Sign in as founder after the review and inspect the recorded rationale before approving. The page keeps source version, scope and account visible in both layouts.

# BL_ACQ
Black River

## Integrated workspace source snapshot

This branch contains the Next.js dashboard, FastAPI backend, and selected development tools and tests. It excludes local datasets, evidence files, the canonical ticket register, and source materials. Workflows that rely on those inputs require an authorized workspace before they can run.

Install JavaScript dependencies with `npm ci` and build the dashboard with `npm run build`. Install the API dependencies with `python -m pip install -r backend/requirements.txt`.

# Independent quality builder agent

The [agent profile](../../.codex/agents/br-quality-builder.toml) defines a development reviewer for source integrity, finance, conditional probabilities, resource scheduling and release evidence.

Start from the ticket's acceptance criteria and reproduce the smallest material risk. Challenge the builder's conclusion against source and executed checks. Distinguish an implemented interface from a verified runtime, and a local result from production readiness.

This profile supports the existing SW-13 review role. Preserve independent
closure in the PROJECT_INTERNAL ticket register. For Doc AI, check native
processing and distinguish disabled, implemented, configured, reachable,
evaluated and enabled providers; a configuration file is not a live connection.

The reviewer reports defects to the owner and keeps edits inside assigned validation paths. It must identify skipped CUDA or R execution, missing deployment evidence and unresolved institutional validation requirements. A schedule estimate is not an operational promise.

Inspect `developer_instructions` for the no-AI runtime check, independent review requirements and action boundary. Validate the TOML with `tomllib` and run `python tools/check_guides.py` after changes.
